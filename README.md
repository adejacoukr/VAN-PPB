# VAN-PPB

Raw vancomycin concentrations (free and total) as measured by HPLC. This dataset was used in the following research project:

Dejaco A, Lier C, Krautbauer S, Kees F, Dorn C, Kees MG. Protein binding of vancomycin in a large mixed patient population at a university hospital. Antimicrob Agents Chemother. 2025, accepted Dec 14. doi: [10.1128/aac.01593-25](https://doi.org/10.1128/aac.01593-25)
